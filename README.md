# Smart Feedback Collection and Analysis System

## 📌 Overview

Smart Feedback Collection and Analysis System is a full-stack web application designed to collect, manage, and analyze employee and customer feedback using Artificial Intelligence.

The application integrates Google Gemini AI to perform sentiment analysis, categorize feedback, identify key issues, and generate intelligent response suggestions. It also provides an interactive admin dashboard to monitor feedback trends and analyze performance.

## ✨ Features

- **User Authentication:** Employee registration and login.
- **Feedback Submission:** Submit feedback with ratings, descriptions, and categories.
- **AI Sentiment Analysis:** Analyze feedback as positive, negative, or neutral using Google Gemini AI.
- **Automatic Categorization:** Classify feedback into relevant categories.
- **Key Issue Extraction:** Identify important problems and concerns from feedback.
- **AI Response Suggestions:** Generate intelligent and professional responses.
- **Admin Dashboard:** Monitor and manage all feedback submissions.
- **Analytics and Reports:** View feedback statistics, sentiment distribution, and trends.
- **Data Visualization:** Interactive charts for category-wise and monthly feedback analysis.
- **Feedback Management:** Search, filter, update, and delete feedback records.
- **Demo Data Generation:** Generate sample feedback for testing and analysis.

## 🏗️ Project Architecture

The application consists of three major components:

- **Frontend:** React and TypeScript provide the user interface, feedback forms, authentication pages, and admin dashboard.
- **Backend:** Node.js and Express.js handle API requests, authentication, feedback processing, and AI integration.
- **Database and AI:** MongoDB stores feedback and employee information, while Google Gemini AI performs intelligent feedback analysis.
